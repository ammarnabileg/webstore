PWA - Progressive Web Application for Botble CMS
Version: 1.1
Author: Motion Media

Installation:
1. Go to Admin > Plugins > Add New.
2. Upload pwa.zip.
3. Activate.
4. Make sure you add this code to your custom html in the appearance settings at the Header HTML <link rel="manifest" href="/manifest.json">
